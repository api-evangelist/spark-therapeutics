# Spark Therapeutics

Spark Therapeutics is a Philadelphia-based gene therapy company founded in 2013 with roots at the Children's Hospital of Philadelphia (CHOP). Spark developed Luxturna (voretigene neparvovec-rzyl), the first FDA-approved gene therapy for a genetic disease in the United States, approved in December 2017 for inherited retinal dystrophy caused by biallelic RPE65 mutations. Roche acquired Spark in December 2019 for approximately $4.3 billion, and Spark now operates as a Roche subsidiary integrated alongside Genentech.

## APIs

No public commercial developer APIs, OpenAPI specifications, SDKs, CLIs, or GitHub organization were identified for Spark Therapeutics. The legacy sparktx.com domain now redirects to `gene.com/spark`, and the brand has been fully absorbed into Roche's web presence. As a Roche subsidiary focused on rare-disease gene therapy, Spark's public technical surface is limited to:

- Patient and prescriber information for Luxturna
- The MySparkGeneration patient support resource
- Adverse event reporting via FDA MedWatch and 1-855-SPARKTX
